# คู่มือ Discord Markdown สำหรับคำอธิบายร้าน YAAN Marketplace

ผู้ขายสามารถใช้ Discord Markdown ในช่อง **คำอธิบายร้าน** ได้ โดยระบบจะแสดงรูปแบบใน Embed หน้าร้านให้อัตโนมัติ ไม่จำเป็นต้องใส่ HTML หรือส่งรูปเพื่อจัดข้อความ

## รูปแบบที่ใช้บ่อย

| ต้องการ | พิมพ์แบบนี้ | ผลลัพธ์ |
| --- | --- | --- |
| ตัวหนา | `**ข้อความ**` | **ข้อความ** |
| ตัวเอียง | `*ข้อความ*` | *ข้อความ* |
| ขีดเส้นใต้ | `__ข้อความ__` | __ข้อความ__ |
| ขีดฆ่า | `~~ข้อความ~~` | ~~ข้อความ~~ |
| หัวข้อ | `## ชื่อหัวข้อ` | หัวข้อใหญ่ |
| หัวข้อย่อย | `### รายละเอียด` | หัวข้อย่อย |
| รายการ | `- รายการแรก` | รายการแบบ bullet |
| รายการเรียงลำดับ | `1. ขั้นตอนแรก` | รายการแบบตัวเลข |
| อ้างอิง | `> ข้อความสำคัญ` | ข้อความแบบ quote |
| โค้ดสั้น | \`คำสั่ง\` | `คำสั่ง` |
| ลิงก์ | `[ชื่อเว็บไซต์](https://example.com)` | ลิงก์ที่กดได้ |

## ตัวอย่างคำอธิบายร้าน

คัดลอกตัวอย่างนี้ไปปรับใช้ได้เลย:

```md
## ✦ ร้านของเรา

ยินดีต้อนรับสู่ **Moon Store** 🌙
ร้านรวมไอเทมและบริการสำหรับคนในย่าน

### 📦 สินค้าของเรา
- **แพ็กเริ่มต้น** — เหมาะสำหรับมือใหม่
- *แพ็กพิเศษ* — จำนวนจำกัด
- บริการตอบแชตในเวลาทำการ

### 🧾 วิธีสั่งซื้อ
1. เลือกสินค้าที่ต้องการ
2. กดติดต่อเจ้าของร้าน
3. ตกลงรายละเอียดและช่องทางชำระเงินกันใน DM

> กรุณาตรวจสอบรายละเอียดก่อนยืนยันการซื้อ

-# ขอบคุณที่สนับสนุนร้านเล็ก ๆ ของเรา 💜
```

## เคล็ดลับให้อ่านง่าย

- ใช้หัวข้อ `##` หรือ `###` แบ่งส่วน เช่น สินค้า วิธีสั่งซื้อ และเงื่อนไข
- ใช้ **ตัวหนา** เฉพาะราคา ชื่อแพ็ก หรือข้อมูลสำคัญ
- เว้นบรรทัดระหว่างส่วนต่าง ๆ อย่าใส่อีโมจิมากเกินไป
- คำอธิบายร้านจำกัด **1,000 ตัวอักษร** และส่วนที่แสดงบนการ์ดร้านมีขีดจำกัดของ Discord Embed
- แก้ไขคำอธิบายผ่านปุ่ม **จัดการร้าน → แก้ไขข้อมูล** ได้ทุกเมื่อ

## ข้อควรทราบ

- Discord Markdown ใช้ตกแต่งข้อความเท่านั้น ไม่ได้เพิ่มความน่าเชื่อถือหรือยืนยันความปลอดภัยของร้าน
- ระบบป้องกันการแจ้งเตือนจากข้อความ mention และ mass mention ในคำอธิบายร้าน
- อย่าใส่รหัสผ่าน, token, ข้อมูลส่วนตัว หรือข้อมูลชำระเงินที่ไม่ควรเปิดเผยในคำอธิบายสาธารณะ
- YAAN Marketplace ไม่รับเงินกลาง ไม่ตรวจสลิปอัตโนมัติ และ Verified Seller ไม่ใช่การรับประกันการซื้อขาย
